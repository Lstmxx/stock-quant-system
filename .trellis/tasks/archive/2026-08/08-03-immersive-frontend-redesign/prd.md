# 全站前端沉浸式视觉重构

## Goal

把 Stock Quant 前端从默认管理后台体验升级为统一的沉浸式量化研究工作台：保留现有业务流程与数据接口，建立具有强烈品牌识别度、实验性排版和细腻动效的全站视觉系统。

## Requirements

- 全站所有界面图标统一使用 `lucide-react`，移除新增或保留的 Ant Design 图标引用；界面文案与图形中不得使用表情符号。
- 覆盖登录页、全局导航壳层，以及 `/data`、`/llm`、`/llm-selection`、`/factor/*` 现有页面的视觉容器与反馈状态；不得改变现有 API、路由、任务轮询和表单行为。
- 建立深色高对比视觉语言：墨黑画布、酸性黄/电光蓝点缀、细线网格、等宽数据标注、巨型标题与层次化留白。
- 导航、按钮、卡片、表格、抽屉、弹窗和错误/加载状态共享同一组 token 与交互语义，支持桌面和窄屏布局。
- 增加可控的 CSS 动效（进入、悬停、背景光晕、扫描/流动感），遵守 `prefers-reduced-motion`，避免影响任务操作与可读性。
- 使用语义化按钮、焦点样式和足够的颜色对比，不能为视觉效果牺牲可用性。

## Acceptance Criteria

- [ ] `rg "@ant-design/icons|Outlined|Filled|TwoTone" apps/web/src` 不再命中前端业务代码；图标来自 `lucide-react`。
- [ ] 登录页与受保护页面均呈现统一的视觉系统，桌面宽度无明显溢出，窄屏导航可操作。
- [ ] 所有现有路由可正常加载，数据表格、弹窗、抽屉、登录/退出和任务操作行为保持不变。
- [ ] `bun run --cwd apps/web build` 通过；无 TypeScript 编译错误。
- [ ] 动效在 `prefers-reduced-motion: reduce` 下被弱化或关闭，键盘焦点可见。

## Scope boundary

- 不改动后端接口、数据库、鉴权协议和业务数据结构。
- 不重写每个业务模块内部的数据获取逻辑；仅在页面级容器和共享视觉层调整布局与样式。
- 推荐先完成全局壳层与登录页，再以共享 CSS token 统一既有业务页面。
