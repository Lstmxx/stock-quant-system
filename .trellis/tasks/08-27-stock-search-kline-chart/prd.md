# 新增股票搜索与K线图模块

## Goal

新增独立的股票行情查询模块。用户可以输入股票代码或股票名称，从主板股票池中搜索并选择股票，随后查看该股票最近一段已采集的日线 K 线和成交量。

## Requirements

- 新增独立的行情图表页面和导航入口，不改变现有股票数据采集任务页面的职责。
- 搜索同时支持股票代码和股票名称，结果应显示代码与名称；搜索结果只来自当前主板股票池，避免将任意字符串直接当作远程股票代码请求。
- 查询和行情接口必须经过现有认证边界；数据范围是全局行情缓存，不按用户隔离。
- 使用稳定单股缓存 `kline:{code}` 读取最近已采集数据，并兼容缓存迁移期间需要的旧日期范围缓存读取逻辑。
- K 线至少展示日期、开盘价、最高价、最低价、收盘价和成交量；缺少缓存或股票无有效行情时显示可理解的空状态。
- 图表使用 `lightweight-charts` v5 的 `createChart`、`CandlestickSeries` 和 `HistogramSeries`，在 React 生命周期中创建和销毁，时间序列按升序且无重复日期。
- 搜索输入、加载、错误、空结果和图表状态具备键盘可用性及可见反馈；请求切换股票时不能让旧响应覆盖新选择。
- 为搜索匹配、行情响应转换、空缓存/错误响应和图表数据转换增加确定性测试。

## Acceptance Criteria

- [ ] 用户从导航进入独立行情页面，输入股票代码或名称后能看到匹配结果，并能选择股票。
- [ ] 选择股票后，页面展示最近已采集的日线蜡烛图和成交量图；数据日期升序、无重复日期。
- [ ] 搜索不存在的股票、股票无缓存或接口失败时，页面显示明确状态，不出现空白或运行时异常。
- [ ] 连续快速切换股票时，最终选择对应的行情显示，旧请求结果不会覆盖新结果。
- [ ] 未认证用户不能访问新 API 或页面；现有数据采集页面和任务接口行为不回归。
- [ ] 新增 Web/API 测试通过，`lightweight-charts` typings 与项目实际安装版本一致，相关 lint/build 通过。

## Confirmed Context

- Web 使用 React 19、Vite 8、React Router 7 和 Ant Design 6；全局样式使用项目已有语义色彩 token。
- 当前 API 已有认证的 `GET /api/tasks/data-collection/stock-names`，但没有行情查询接口。
- 当前 Engine 的 `/internal/fetch-data` 会调用 `load_latest()` 构建全市场数据，不作为搜索页面的按股票查询接口。
- 稳定单股缓存的 payload 是 JSON 行数组，字段顺序为 `date,code,open,high,low,close,volume,amount,turn,pctChg`。
- 无缓存时只展示“请先执行数据采集”的空状态，不在搜索操作中触发 Baostock 请求；数据采集任务是行情写入的唯一入口。
