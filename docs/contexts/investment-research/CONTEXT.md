# 投研决策上下文

## 使命

把行情、自选股和已评估因子组织成可供研究者审阅的个股分析、策略模拟与报告；输出是研究材料，不是自动交易指令。

## 边界

包含：

- 维护用户自选股
- 发起单股分析或自选股扫描
- 组织趋势、信号、风险和建议等分析结果
- 按研究风格推荐或组合因子
- 模拟因子/策略表现并生成 Markdown 研究报告

不包含：

- 定义因子有效性的评估标准
- 行情采集和缓存生命周期
- 订单执行、仓位管理和真实收益归因

## 核心规则

- 分析报告必须标明标的和分析日期，并与生成它的用户及任务关联。
- `BUY`、`HOLD`、`SELL`、`WATCH` 是研究报告中的模型建议，不是订单。
- 策略引用因子及约束；因子本身不等同于策略。
- 模拟结果是研究估算，不应表述为已实现收益。
- 用户只能读取和修改自己的自选股、报告与策略。

## 术语表

| 术语 | 定义 | 避免使用 |
| --- | --- | --- |
| 自选股 | 用户主动维护、用于观察或批量分析的股票集合 | 持仓 |
| 个股分析 | 基于行情、技术信号、因子和 LLM 解释形成的研究结果 | 交易信号（整体报告不等于单一信号） |
| 分析建议 | 报告中的 `BUY/HOLD/SELL/WATCH` 研究标签 | 订单、指令 |
| 量化策略 | 因子组合、研究风格和约束的配置 | 因子 |
| 策略模拟 | 基于历史研究数据计算的表现估计 | 实盘业绩 |
| 研究报告 | 面向研究者审阅的结构化结果或 Markdown 文本 | 投顾报告 |

## 协作关系

- 消费**市场数据**的行情与价格摘要。
- 消费**因子研究**的有效因子和评估指标。
- 依赖**平台运行**完成用户隔离、LLM 调用和任务状态管理。

## 代码地图

- 个股分析：`apps/api/src/modules/analysis`
- 自选股：`apps/api/src/modules/watchlist`
- 策略与报告：`apps/api/src/modules/strategy`
- Web 功能：`apps/web/src/features/dashboard` 及相关 feature 目录
- 持久化：`packages/database/src/schema.ts` 中的 `watchlists`、`quantStrategies`、`alphaTasks`
