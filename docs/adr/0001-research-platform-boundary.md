# ADR-0001：将系统限定为研究与工程实验平台

- 状态：已接受
- 日期：2026-07-13

## 背景

仓库包含行情采集、因子挖掘、策略模拟和带有 `BUY/HOLD/SELL/WATCH` 标签的分析结果。如果不明确产品边界，文档和后续实现容易把研究能力描述成生产级交易能力。

个人或小团队是当前主要使用者。系统仍处于快速实验阶段，尚未建立券商接入、订单状态机、资金与仓位账本、生产级风控、审计和高可用运维能力。

## 决策

将 Stock Quant System 定义为**个人/团队量化研究与工程实验平台**。

- 行情、因子、分析、模拟和报告均属于研究用途。
- 模型生成的建议是研究标签，不是交易指令。
- 实盘订单执行、券商账户、资金托管、仓位管理和生产级风险控制不属于当前系统边界。
- 面向用户的全局文档必须包含研究用途和非投资建议声明。

## 影响

- 可以围绕研究速度、可解释性和可重复性优化，无需假装满足交易系统级别的可靠性承诺。
- 新增实盘交易能力时，必须另行评审边界、安全、合规与运行风险，并用新的 ADR 修改本决策。
- 命名和文案应区分“模拟表现”与“实盘业绩”、“分析建议”与“订单”。
